# Using MDX

[Documentation index](README.md) · [Content guide](CONTENT.md)

MDX support is already enabled in astro.config.mjs. Use .md for ordinary prose
and .mdx when an article needs an imported component or JavaScript expressions.
Frontmatter uses the same article schema as Markdown.

Imports go after frontmatter. For a file three directories below src, a relative
component import would look like this (substitute a component that actually exists):

```mdx
import ArticleDiagram from '../../../components/ArticleDiagram.astro';

<ArticleDiagram />
```

This example does not install or define ArticleDiagram. Rendering a component
does not automatically provide client-side interactivity; follow that component's
own script/framework requirements. Preview and build after introducing MDX syntax.
